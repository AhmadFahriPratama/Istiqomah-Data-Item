# Istiqomah Data v2.1.0

Aplikasi **offline** untuk **Windows Desktop** dan **Android** guna mengolah ekspor data item Excel / CSV / SQL / JSON dari **iPos 5** tanpa mengubah database asli iPos.

## Fitur Utama
- **Deteksi Perubahan & Impor Otomatis iPos 5**: Otomatis mendeteksi barang baru, harga naik/turun, perubahan mode harga, dan stok menipis pada setiap sinkronisasi file ekspor Excel/CSV/SQL/JSON terbaru.
- **Kontrol Laba & Margin**: Memisahkan level harga **Ecer** vs **Grosir** serta multi-satuan, dilengkapi indikator lampu merah/kuning/hijau, saran pembulatan harga jual, dan ekspor Excel / PDF.
- **Order Supplier Otomatis (Excel Tanpa Harga)**: Mengelompokkan kebutuhan order per prefix supplier dengan **Ekspor Excel rapi tanpa kolom harga**, ekspor PDF, serta format pesan WhatsApp siap kirim.
- **Studio Tag Harga Bersih & Fleksibel**: Menampilkan **Nama Produk**, **Harga Jual (`Rp.`)**, **Grosir kecil** (jika tersedia), dan **kode barcode teks saja** (tanpa gambar garis barcode agar lebih mudah ditempatkan di rak; item tanpa barcode tidak menampilkan kode item).
- **Printer & Kertas Lengkap**: Mendukung **Thermal 58mm**, **Thermal 80mm**, **Kertas A4 Grid**, **Kertas A5 Grid**, **Kertas F4 Grid**, **Stiker Label A4**, cetak langsung Printer Windows, ekspor PDF siap cetak, gambar PNG, ESC/POS, serta Bluetooth Android.
- **Retur Barang per Supplier**: Pencatatan retur internal lengkap dengan surat jalan PDF dan rekap Excel.
